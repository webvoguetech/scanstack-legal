# ScanStack — legal pages

Public site for the ScanStack Android app: privacy policy and terms of service.

Served with GitHub Pages from the root of this repository. Plain static HTML,
no build step, light and dark aware.

- [Privacy Policy](https://webvoguetech.github.io/scanstack-legal/privacy.html)
- [Terms of Service](https://webvoguetech.github.io/scanstack-legal/terms.html)

These URLs are referenced from the app (Settings → Legal) and from the Google
Play listing, so **the file names must not change** once the app is published.

The app source lives in a separate private repository. Edit the copies in its
`docs/` folder and copy them here, so the two do not drift.
